## 配置 LLM API

打开配置页后，首次使用会进入 **配置向导**，按步骤完成即可：

1. **仿真 LLM** — 填写 API 地址、密钥与模型（支持预设与获取模型列表）
2. **保存配置** — 写入工作区 `.env`
3. **启动后端** — 一键保存并启动本地服务
4. **文献 MCP**（可选）— 学术检索网关
5. **CLI 网关**（可选）— Claude Code / Codex

可随时点 **「全部设置」** 切换到完整 Tab 视图。

---

### 必填项

| 配置项       | 说明       | 示例                        |
| ------------ | ---------- | --------------------------- |
| **API Key**  | 服务商密钥 | `sk-...`                    |
| **API Base** | 服务地址   | `https://api.openai.com/v1` |

Fiblab 用户可选用预设 **Fiblab LLM API**，地址为 `https://llmapi.fiblab.net/v1`，与文献 MCP 共用 Key。

填写后点 **验证** 确认连通，再 **保存**。

---

### 常见检查

| 现象         | 优先检查                                          |
| ------------ | ------------------------------------------------- |
| 验证失败     | Key 是否完整；Base 是否含 `/v1`                   |
| 模型列表不对 | 第三方网关只应显示 API 返回的模型，不应混入无关项 |
| 后端未启动   | 是否已保存 `.env`；向导第 3 步是否执行            |
